En esta tarea también tomamos las siguientes decisiones.

\begin{itemize}
  \item No hicimos pruebas de significancia ni de correlación entre campos, porque la entrada del modelo son imágenes y no una tabla de atributos.
  \item No hicimos muestreo ni pesos de atributos. Tenemos pocas vacas y las fotos únicas pesan cerca de 1.80 GB, así que usamos todas las fotos disponibles.
  \item No recolectamos datos adicionales en esta fase.
  \item Si el socio formador responde qué mide ``Evento BCS'', volvemos a evaluar si se usa.
\end{itemize}

\subsubsection*{Cómo obtuvimos las cifras}

Todas las cifras de esta fase salen de correr completo el notebook \nolinkurl{01_dp_bcs_problem.ipynb} sobre las fotos originales (761 archivos), la bitácora (\nolinkurl{etiquetas_bsc.xlsx}), la hoja manuscrita (\nolinkurl{bitacora_hoja_manuscrita.csv}) y el archivo \nolinkurl{vistas.csv} con las vistas marcadas a mano. El notebook baja estos datos del bucket de S3 del equipo y lee las llaves de AWS y el nombre del bucket de los secretos de Colab, para que no queden escritos en el notebook. La corrida terminó sin errores y el índice que generó coincide con el índice de referencia que ya estaba en el bucket (580 filas, mismas columnas y ninguna diferencia), así que el notebook reproduce exactamente el dataset del bucket.
